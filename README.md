# File sorting

A python based file sorting application

Bruker Eel for web basert ui

skal ha file nav, og filtering

## tools

bruker python for backend til fildatafetching og åpning av filer fordi jeg er vant itl det og det har enkle librararies jeg kan bruke til html frontend og file navigation
bruker react bygd til vanilla for frontend fordi jeg er vant til å bruke react

## funksjonalitet

kan sorter søke og åpne filer

## testing

testet med npm run build og py main.py etterpå
fant et par feil langs vegen som at scanning av filer og alle subfiler tar for lang tid så man ikke realistisk kan fullskanne store mapper

## refleksjon

- det gikk bra tok litt lengere tid en jeg hadde tenkt og fikk ikke lagt til noe mange filtering options men er funksjonelt
- var litt utfordrende å bruke python igjen har ikke brukt det siden forgie november tror jeg
- har lært hvordan jeg gjør et python prosjekt om til en exe fil
- ble ferdig litt seint sleit litt med python installs og sånt langs vegen siden jeg har for mange versioner lasted ned pip er plagsomt innimellom
